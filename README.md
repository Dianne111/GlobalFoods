# Global Foods México - App de Gestión de Pedidos (Menudeo)

Sistema multiplataforma diseñado para optimizar la gestión de pedidos de venta al menudeo de la empresa productora y comercializadora de camarón Global Foods México. La aplicación resuelve la discontinuidad digital del proceso de ventas, permitiendo centralizar la información y coordinar de forma estructurada a los equipos de ventas, almacén y reparto.

## Objetivo del Proyecto

El sistema elimina la dependencia operativa de las llamadas telefónicas cuando las asesoras se encuentran fuera de la congeladora. Permite que los pedidos se originen formalmente desde el punto de atención al cliente y lleguen de manera inmediata al almacén para su preparación.

## Características Principales

* **Formalización Remota:** Registro de ventas desde dispositivos móviles o equipos de escritorio sin depender de la ubicación física en la congeladora.
* **Trazabilidad de Estados:** Seguimiento operativo en tiempo real mediante cinco etapas definidas: Pendiente, En preparación, Listo, En reparto y Entregado.
* **Notificaciones Inteligentes:** Uso de agentes de inteligencia artificial para enviar actualizaciones de estatus a los clientes a través de WhatsApp.
* **Control Comercial:** Consulta de disponibilidad de inventario asignado, gestión del catálogo de clientes y registro de formas de pago para el cierre de venta.
* **Supervisión Administrativa:** Generación de reportes operativos para visualizar el desempeño del canal de menudeo.

## Stack Tecnológico

* **Framework:** Kotlin Multiplatform (KMP)
* **Interfaz de Usuario (UI):** Jetpack Compose (Módulo `sharedUI`)
* **Arquitectura de red/API:** Ktor Client (Módulo `sharedLogic`)
* **Plataformas de despliegue:** Android (nativo) e iOS.
